## 概况

[中国医学科学院整形外科医院](http://www.zhengxing.com.cn)（Plastic Surgery Hospital, Chinese Academy of Medical Sciences, PSH）即北京八大处整形美容外科医院，是中国唯一一家集整形美容整容为一体的专科医院。

医院位于[北京市石景山区八大处路 33 号](https://amap.com/place/B000A8316D)。

1. 本人申请书
2. 父母知情同意书（需要公证）

4. 指定医院开具的易性症/性别不一致诊断证明
5. 未在婚姻状态的相关证明（如未到法定结婚年龄，不需要任何关于婚姻状态的证明）

### 预约流程

#### 1.面诊

在现场或“八大处整形医院官方咨询平台”微信小程序预约挂号。\
挂“会阴整形与性别重塑科”中**你希望主刀**的医生的号。

小程序提前7天放号，放号时间为15:00。

面诊时可获得医生助理微信号。

{{< notice info "提示" >}}
面诊时无需备齐全部申请材料，但建议至少准备精神/心理科易性症病历。
{{< /notice >}}

#### 2.提交材料

通过医生助理微信，提交申请材料图片。

1. 本人申请书（不强制要求公证）
2. 父母知情同意书（需要公证）
3. 无犯罪记录证明（由户籍地派出所开具）
4. 指定医院开具的易性症/性别不一致诊断证明
5. 未在婚姻状态的相关证明（户口本即可）

#### 3.伦理会议

八大处的伦理会议大约每3个月召开一次，会先讨论全院的科研项目伦理，然后进行本期SRS伦理审查。

伦理会议通常下午进行，上午将有科室医生对SRS患者与家属进行现场宣讲，讲解SRS术式与预后。

伦理会议需患者本人到场。父母可以选择性到场，或进行电话确认。

伦理会议在基础的伦理性问题之外，会**严格考察**父母的意愿是否明确。

伦理审查结果通常于伦理会议**次日**告知。

{{< notice warning "特别提醒" >}}
伦理会议中会有伦理委员询问较为冒昧的问题。如“既然你是对于原本生殖器有厌恶，那么为什么不直接切平了，还要造一个女性的生殖器出来？”（来自笔者亲身经历）
{{< /notice >}}

{{< notice info >}}
伦理会议通过后将不再有“必须由父母参与”的环节。
{{< /notice >}}

{{< notice info >}}
伦理会议后会归还患者手中的纸质申请材料。
{{< /notice >}}

#### 4.预约排期

伦理会议通过后，**每月月初**向医生助理微信询问**次月**的医生档期。\
预约后即可开始准备手术事宜。
